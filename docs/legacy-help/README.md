# Legacy help files

Help text recovered from the old root-level `world/help/` copy that existed before the repo was
restructured. The game never loaded these files. They're kept here, outside the loader path, as
source material.

To make one live, move it into `world/help/<category>/`. The help key is the filename, so first
check that it doesn't collide with an existing entry: `chargen`, `hunt`, `status` and `xp`
already exist under `world/help/v5/`.
